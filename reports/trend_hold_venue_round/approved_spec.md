## 1. 严格继承 R5 的信号、波动预算与时间表

1. **日线聚合与可用时间**：
   - UTC 日 `d` 覆盖 `[d 00:00, d+1 00:00)`，`available_time = d+1 00:00`；日收盘 `C_d` 取当日最后一根有效 `1m` 收盘价；`bad` 分钟盯市沿用此前最后有效价并单列维护暴露，不冒充新有效日观察；整日无有效分钟则立即停机。
2. **趋势开关与事前波动估计（每日 `00:00` 仅用已闭合日线）**：
   - `M_d = mean(C_{d-60}, ..., C_{d-1})`；策略趋势开关 `g_{T,d} = 1[C_{d-1} > M_d]`（`float64` 严格大于，相等取 `0`）；持续多头基准 `g_{P,d} = 1`。
   - 日简单收益 `u_j = C_j / C_{j-1} - 1`；事前年化波动 `sigma_d = sqrt(365) * std(u_{d-20}, ..., u_{d-1}, ddof=1)`。
3. **周度预算更新日历（修正对齐 R5 第 3 节）**：
   - 共同预算 `L_d = min(1.0, 0.20 / sigma_d)`（若 `sigma_d == 0` 取 `1.0`；非有限或负值停机）。
   - **更新时间**：仅在**规范序列主窗口起点决策日 `00:00` 及此后每个 UTC 周一 `00:00`** 更新；其余日沿用最近一次预算值。`T` 处于 `OFF`（`g=0`）期间也照常在周一更新共同预算 `L_d`，非周一重新入场直接沿用最近周一的 `L_d`。
4. **信号源规则**：
   - **主实验（Primary）**：同一标的（`BTC` 或 `ETH`）下所有载体共享**同一份规范 `(g_d, L_d)` 时间表**，由该标的 `USDⓈ-M` 永续 `1m` 聚合日线生成（`BTC` 预热期为 `2020-01 ~ 2020-02`；`ETHUSDT` 永续自 `2020-07 ~ 2020-08` 即具备完整 60 日原生预热）。
   - **COIN-M 自信号诊断（Diagnostic）**：单独在完整满 60 根 `COIN-M` 原生日线预热后的共同窗口 **`IS-CM-SelfSignal = [2020-11-01 00:00, 2024-01-01 00:00)`（38 个自然月）** 上，用 `COIN-M` 自身 `1m->1D` 收盘序列独立生成 `(g_d^{CM}, L_d^{CM})` 运行 `V3 / V4`，报告与主信号的开关一致率及净值差异。

### 2.3 下单触发日历与同边界严格执行顺序

1. **下单触发条件（与 R5 第 4.1 节完全一致）**：仅当满足以下任一条件时，在日 `d` 的 `00:00` 边界计算新目标仓位：(a) 评估窗口首次决策日、(b) UTC 周一预算更新日、(c) 当日 `g_d != g_{d-1}`、(d) 前一日因 `00:00` 执行分钟 `bad` 取消而留有 `pending` 标记。同一天多原因合并为单次净调整；若 `00:00` 执行分钟为 `bad`，按 R5 规则取消本次订单并置 `pending=True`，留待次日 `00:00` 重新决策（不顺延到盘中恢复分钟）。
2. **同边界固定三步时序（严禁颠倒）**：
   - **Step 1（事前冻结目标）**：使用边界前上一分钟（`d-1 23:59`）收盘盯市权益（不含即将发生的 `00:00` 资金费）与载体自身前一日收盘参考价冻结目标仓位；
   - **Step 2（旧仓结算资金费）**：若该时刻为资金费结算点 $\tau$，对**交易前旧持仓**结算资金费（`gross_0` 记 `0`）；
   - **Step 3（执行净调仓）**：在 `d 00:00` 的 `1m` 开盘价上按买卖方向施加滑点与手续费执行净差额。

### 2.4 各载体精确记账公式

#### (A) `V1_USDM` / `P_USDM`
- 完全复用 `R5` 冻结线性 USDT 合约引擎：`q_target = g_d * L_d * E^-_d / C_{d-1}^{UM}`，资金费 `-q_old * P_ref_tau * r_tau^{UM}`（正常 `P_ref_tau = O_tau^{UM}`，`bad` 取最后有效价）。

#### (B) `V2_SPOT` / `P_SPOT`（含现金非负硬约束裁剪）
- 账户由现金 `B_t >= 0`（USDT）与现货持仓数量 `q_t >= 0` 组成，盯市净值 `E_t = B_t + q_t * S_t`（$S_t$ 为现货 `1m` 收盘价），无资金费。
- 事前目标数量：`q_star = g_d * L_d * E^-_d / C_{d-1}^{Spot}`，理想调整量 `dq_raw = q_star - q_old`。
- 执行价格：买入 `dq_raw > 0` 时 `F_buy = O_d^{Spot} * (1 + buy_slip)`；卖出 `dq_raw < 0` 时 `F_sell = O_d^{Spot} * (1 - sell_slip)`。
- **现金上限部分成交规则（预注册固定规则）**：
  - 若 `dq_raw > 0`：实际成交量 `dq_fill = min(dq_raw, B_old / (F_buy * (1 + f)))`，成交后 `B_new = B_old - dq_fill * F_buy * (1 + f)`（浮点尾差若在 `[-1e-12, 0)` 夹零，若 `< -1e-9` 视为错误停机），单列记录现金裁剪次数与裁剪比例；
  - 若 `dq_raw < 0`：实际卖出量 `dq_fill = max(dq_raw, -q_old)`（全清时精确取 `-q_old`），成交后 `B_new = B_old + |dq_fill| * F_sell * (1 - f)`。

#### (C) `V3_CM_DeltaMatched` / `P_CM_DeltaMatched` / `V4_CM_CoinAccum` / `HODL_1x_Coin`
1. **统一起点换币公式（保证币本位组与现金组 100% 公平同源）**：
   - 在评估窗口起点 `d_0 00:00`，用 `100,000 USDT` 按当日 `00:00` 现货开盘买入价 `F_{buy,0}^{Spot} = O_{d_0}^{Spot} * (1 + buy_slip)` 及费率 `f` 一次性换得初始钱包币数（若起点 `00:00` 现货分钟 `bad` 则停机）：
     $$C_0 = \frac{100,000}{F_{\text{buy},0}^{\text{Spot}} \cdot (1 + f)}$$
   - `V3`、`P_CM`、`V4` 与 `HODL_1x_Coin` 在同一成本档位下严格共享完全相同的 $C_0$（`gross_0` 下即 `100,000 / O_{d_0}^{Spot}`）。
2. **币权益（Coin Equity）定义（含未实现盈亏）**：
   - 设钱包已实现币余额为 $W_t$，当前反向合约带符号美元面值为 $N_t$（多正空负，主实验采用浮点连续美元面值，另在诊断表报告按 `BTC=100 USD / ETH=10 USD` 整张取整结果），持仓成本均价/上次盯市参考价对应的未实现盈亏并入后的**账户总币权益**为 $C_t$：
   - 在任意无交易、无资金费的价格变动 $P_{t-1}^{\text{CM}} \to P_t^{\text{CM}}$ 上，币权益递推恒等式为：
     $$C_t = C_{t-1} + N_{t-1} \left(\frac{1}{P_{t-1}^{\text{CM}}} - \frac{1}{P_t^{\text{CM}}}\right)$$
     （代码中须同时维护 `wallet_coin` 与 `unrealized_pnl_coin` 并逐分钟断言 `abs(coin_equity - (wallet_coin + unrealized_pnl_coin)) <= 1e-12`）。
3. **事前目标面值冻结（Step 1）**：
   - 在触发日 `d 00:00`，用上一分钟币权益 $C_{d^-}$（窗口首日建仓前即 $C_0$）与前一日 `COIN-M` 收盘价 $C_{d-1}^{\text{CM}}$ 冻结目标美元面值：
     - `V3_CM_DeltaMatched` / `P_CM_DeltaMatched`：$N_{\text{target}, d} = (g_d L_d - 1.0) \cdot C_{d^-} \cdot C_{d-1}^{\text{CM}}$（注意：每周一即使 `g_d = 0` 也会按最新币权益 $C_{d^-}$ 重算 $-C_{d^-} C_{d-1}^{\text{CM}}$，自动将上周累积的资金费币纳入套保）；
     - `V4_CM_CoinAccum`：$N_{\text{target}, d} = + g_d L_d \cdot C_{d^-} \cdot C_{d-1}^{\text{CM}}$。
4. **旧仓资金费结算（Step 2）**：
   - 使用 Binance Vision 官方 `futures/cm` 专属历史资金费率 $r_\tau^{\text{CM}}$。在结算点 $\tau$，先将币权益盯市至结算参考价 $P_{\text{ref},\tau}^{\text{CM}}$（正常取 $O_\tau^{\text{CM}}$，`bad` 取最后有效价，作为标记价格的一致近似），再对旧仓 $N_{\tau^-}$ 结算币数资金费并记入钱包余额：
     $$\Delta C_{\text{fund},\tau} = - \frac{N_{\tau^-}}{P_{\text{ref},\tau}^{\text{CM}}} \cdot r_\tau^{\text{CM}}$$
     （仅当 $N_{\tau^-} < 0$ 且 $r_\tau^{\text{CM}} > 0$ 时净收币；若 $r_\tau^{\text{CM}} < 0$ 则空头付币，严禁预设必然正收益）。
5. **净调仓成交与不重复计滑点的精确费用公式（Step 3）**：
   - 设调仓前已将旧仓盯市至当根开盘参考价 $P = O_d^{\text{CM}}$，净面值调整量 $\Delta N = N_{\text{target}, d} - N_{\text{old}}$。
   - 若 $\Delta N > 0$（买入开多或买平空单），成交价 $F = O_d^{\text{CM}}(1 + \text{buy\_slip})$；若 $\Delta N < 0$（卖出开空或卖平多单），成交价 $F = O_d^{\text{CM}}(1 - \text{sell\_slip})$。
   - 本笔交易对总币权益 $C$ 的即时净变动（含滑点损益与成交手续费，严禁二次重复扣滑点）精确为：
     $$\Delta C_{\text{trade}} = \Delta N \left(\frac{1}{F} - \frac{1}{O_d^{\text{CM}}}\right) - f \cdot \frac{|\Delta N|}{F}$$
6. **简化维持保证金压力监控模型（明确标注模型性质）**：
   - 明确登记：因不使用交易所历史逐档维持保证金表与独立标记价格流，本实验采用**固定 `MMR = 0.005`（`0.5%`）+ 合约有效 `1m` K 线极值价（`N > 0` 取 `Low`，`N < 0` 取 `High`）的简化维持保证金压力模型**。
   - 判据：若某有效分钟极值价 $P_{\text{ext}}$ 下满足
     $$C_{\text{before}} + N \left(\frac{1}{P_{\text{before}}} - \frac{1}{P_{\text{ext}}}\right) \le 0.005 \cdot \frac{|N|}{P_{\text{ext}}}$$
     （对多头 $N > 0$ 等价于 $P_{\text{ext}} \le P_{\text{liq}} = \frac{N(1 + 0.005)}{C_{\text{before}} + N / P_{\text{before}}}$），则判定触发简化压力强平，立即终止该账户后续交易、冻结并记录触线时刻剩余正权益快照（如测试 B 在 $25,125$ 触线时剩余 $250\text{ USD}$ 权益，不与忽略强平的理论归零点 $25,000$ 混同），此后净值曲线保持该冻结残值直至窗口结束并显式标记 `liquidated = True`。
7. **双口径估值与窗口末端清算对账**：
   - 持仓期间每日末同时记录两套美元估值：(i) **合约内生美元净值** $E_t^{\text{CM-USD}} = C_t \cdot P_t^{\text{CM}}$；(ii) **现货折算美元净值（含期现基差）** $E_t^{\text{Spot-USDT}} = C_t \cdot S_t^{\text{Spot}}$。
   - 在独立评估窗口最末一分钟（IS 为 `2023-12-31 23:59`，Post-IS 为 `2026-10-31 23:59`）收盘：先按收盘价加对应方向滑点与费率将合约残余面值 $N$ 平至 `0` 得到最终币数 $C_{\text{final}}$（用于考核币增长率 $C_{\text{final}} / C_0 - 1$）；再对需要现金闭环对比的主口径按同分钟现货收盘卖出价 $F_{\text{sell,end}}^{\text{Spot}} = S_{\text{end}}^{\text{Spot}}(1 - \text{sell\_slip})$ 与费率 $f$ 折算最终可提现 `USDT` 净值 $E_{\text{final}}^{\text{Cash-USDT}} = C_{\text{final}} \cdot F_{\text{sell,end}}^{\text{Spot}}(1 - f)$（同时保留不卖回 USDT 的 $C_{\text{final}} \cdot S_{\text{end}}^{\text{Spot}}$ 供对照）。

### 2.5 可逐笔对账的收益分解规范（替代原伪凸性四分法）

删除“独立的 USD 反向合约凸性项”。统一采用两层严格可对账分解：
1. **单账户内部逐笔闭合台账（误差 `< 1e-9`）**：
   - 币本位账户（币口径）：`C_final - C_0 = 合约参考价盯市损益币 + 资金费净收支币 + 调仓滑点币损益 - 交易手续费币`；
   - 币本位账户（现货 USDT 闭环口径）：`E_final^{Cash-USDT} - 100,000 = 初始/末端换币摩擦 + 底仓币现货价格变动损益 + 反向合约损益按当期现货价折算额 + 资金费折算额 + 合约调仓滑点与手续费折算额`（各项逐分钟/逐日精确闭合）。
2. **跨载体差异解释**：
   - **同目标敞口组（`V1_USDM` vs `V2_SPOT` vs `V3_CM_DeltaMatched`）**：直接对比同现金闭环净值差，拆分为资金费收支差、交易/换币摩擦差、期现/跨合约价格基差与现金上限/周度重套保路径交互项；
   - **额外底仓敞口组（`V4_CM_CoinAccum`）**：明确标为 `1 + g_d*L_d` 敞口模式，主基准为同起点 `HODL_1x_Coin`（考核纯超额赚币率 $C_{\text{final}} / C_0 - 1$），不与 `V1/V2/V3` 混作等风险载体优劣排名。

## 4. 统计检验与绩效指标精确公式（100% 继承 R5 第 6 节）

1. **配对统计检验（主成本 `main_17`，载体内部同预算配对 `T` vs `P`）**：
   - 对每个同目标敞口载体（`USDM`、`SPOT`、`CM_DeltaMatched`）及各评估窗口（设窗口总天数为 $N$，自然月数为 $G$），定义日收益 $r_d = E_{d,23:59}/E_{d-1,23:59} - 1$ 及同日差 $D_d = r_{T,d} - r_{P,d}$。
   - 沿用 `R5` 完全相同的**按自然月聚类受约束 Webb 六点野自助 t 检验**：`Generator(PCG64(2026111001))`，权重集 `[-sqrt(1.5), -1, -sqrt(0.5), sqrt(0.5), 1, sqrt(1.5)]`，一次生成 `size=(99999, G)`，检验载体内部单侧两假设 `H_T: mean(r_T) <= 0` 与 `H_D: mean(D) <= 0`（Holm 族大小固定为 `2`，并列 `T` 优先，完全沿用 R5 退化判据；明确披露该 Holm 仅作单一载体-窗口内部的描述性参考，不作跨多载体/多窗口的全局多重检验宣称）。
   - 95% 置信区间沿用 `Generator(PCG64(2026111002))` 整月有放回抽样 `integers(0, G, size=(10000, G))`，`linear` 百分位法。
2. **绩效指标统一固定公式**：
   - **累计净收益**：$R_{\text{cum}} = E_{\text{end}} / E_{\text{start}} - 1$；
   - **CAGR**：$(E_{\text{end}} / E_{\text{start}})^{365 / N} - 1$（若 $E_{\text{end}} \le 0$ 记 `NA`）；
   - **实现年化日波动率**：$\sigma_{\text{ann}} = \sqrt{365} \cdot \operatorname{std}_{\text{ddof}=1}(r_1, \dots, r_N)$；
   - **日夏普（Sharpe）**：$\sqrt{365} \cdot \operatorname{mean}(r) / \operatorname{std}_{\text{ddof}=1}(r)$（零标准差记 `NA`）；
   - **日索提诺（Sortino）**：$\sqrt{365} \cdot \operatorname{mean}(r) / \sqrt{\frac{1}{N}\sum_{d=1}^N \min(r_d, 0)^2}$（分母为 0 记 `NA`）；
   - **1m 最大回撤（1m MaxDD）**：基于有效 `1m` 收盘盯市净值序列 $\max_t (1 - E_t / \max_{s \le t} E_s)$；
   - **卡尔玛（Calmar）**：$\text{CAGR} / \text{1m\_MaxDD}$（分母为 0 或 CAGR 为 `NA` 时记 `NA`）。
