## 本阶段入口

`python tools/run_breakout_study.py --check` 只核验登记、代码和旧冻结资产，不读取行情。省略参数亦为此模式。

`python tools/run_breakout_study.py --real` 在本阶段立即拒绝，既有 impulse 引擎的解锁状态不会解锁本研究。没有 CLI 解锁、改种子、减采样或改参数开关。

`python tools/run_breakout_study.py --synthetic --output /tmp/channel-vah-synthetic-example` 只生成虚构价格进行集成验证，输出目录须在仓库之外且原先不存在。它不会读真实价格，也不具有投资含义。阶段测试已覆盖此流程，不必为审查重复运行。

测试使用仓库外的 Python 3.14.4 / pandas 3.0.5 / NumPy 2.5.4 环境；不用修改现有 requirements.txt。运行时不联网下载、不修补缓存、不读现货预热。

## 实现选择登记（不改变研究定义）

- 真实价格、资金费均采用加载入口的双边 IS 谓词；资金费另校验完整 4,383 项分钟结算网格。读取已存在的永续缓存并核对原 manifest 内容哈希，不自动重建。
- 非交易的 bad 分钟只用此前有效收盘价格前向填充盯市/资金费参考，不向后填充。初始缺乏因果参考价格或未能在 IS 内完成退出时停止。
- 输入数组采用独立不可写快照。合成输入须显式带 `provenance=synthetic`；此标记防止调用方误用，不防恶意伪造来源。
- 事件审计固定列出 2020-03-12、2021-05-19 全部 24 个 UTC 整点边界之后的持仓状态，不挑选有利时刻；月度汇总同时报告 2020-03、2021-05。
- 归档缺口审计包含参考窗口、压缩历史、成交量历史和 ATR 递归历史；这些标记不排除交易或改变信号。
- 门禁的非正净值排除还接受撮合器的永久失败标记，避免盘中净值非正后恢复到正值被日末统计掩盖。
- 如零净值导致日收益无定义，保留组合台账，并按已批准的异常停止规则终止统计；不以补零收益或删除日期掩盖错误。
- 统计公开入口没有采样次数或种子覆盖；低层纯函数接受合成矩阵仅供手算回归。新模块不使用旧 CP3 的十版本统计封装。
- “换手”定义为累计双边实际成交名义金额 / 初始资金，持仓占比为台账持仓分钟合计 / 主窗口分钟数。最大回撤包括初始资金锚点；按入场月的删月检查不重新撮合。
- 合成测试通过显式 pytest 插件禁止行情文件和网络访问；未全量收集旧测试，避免触发真实数据用例。相关 CP2 测试明确排除两个真实数据测试。
