# 脉冲研究实验计划（预注册，Checkpoint 2 冻结）

适用范围：“日线箱体二段反弹 + 时间价格脉冲”（A 组）与“完全去掉箱体 · 纯时间价格脉冲”（B 组）双轨对照研究，以及 SL_A / SL_B / SL_C 三种客观止损的比选。全部阶段只使用 Binance BTCUSDT USDⓈ-M 永续的 IS 区间 [2020-01-01 00:00 UTC, 2024-01-01 00:00 UTC)，外加 2020 年之前的现货日线价格预热；不下载、不读取、不运行任何 VAL、OOS 或 ETH 的数据与绩效。

本计划在任何真实逐笔盈亏、净值曲线或收益统计出现之前提交。冻结物有三件：本文件；`impulse_study/versions.py` 中的 10 个版本、成本、仓位、常数、A 组箱体口径与漏记分钟清单（`frozen_key()` 见第 13 节）；第 13 节按 SHA256 列出的引擎、特征与数据代码（`impulse_study/engine.py`、`features.py`、`synthetic.py`、`signals.py`、`daily.py`、`data_1m.py`、`scope.py` 等）。第 3 阶段只按这里的定义一次性运行，不增删版本、不改动任何参数或判定规则，不在看到结果后切换主口径。本文与代码不一致时，以用户在 Checkpoint 2 审批中的裁定为准，并按第 12 节的变更规则处理。

## 2. 脉冲触发器

### 2.1 百分比口径（主口径）

r_k = C_T / C_{T−k} − 1（k = 1, 5, 15，取 UTC 分钟网格上 T−k 那一根的收盘价），端点为 `bad` 分钟时收益率缺失、不触发。指标 ①：r1 ≥ +0.18% 且 r5 ≥ +0.47%（向下：r1 ≤ −0.18% 且 r5 ≤ −0.47%）；指标 ②：r15 ≥ +1.18%（向下：r15 ≤ −1.18%）。Up_Impulse = ① ∨ ②，Down_Impulse 同理。每个信号按其所依据的脉冲方向（A4 为向下脉冲；其余版本与入场方向相同）、在版本自身的阈值口径下记录触发类别：仅 ①、仅 ②、① + ②。回看窗口 [T−15, T] 内含 `bad` 分钟的触发记为“维护污染”，不可交易。实现为 `impulse_study/signals.py`（与 Checkpoint 1 相同，未改动）。

### 2.2 Z-score 口径（A5、B5）

三个阈值同乘 σ7d(T) / σ_ref。σ7d(T) 为截至 T−15 的 10,080 根 1m 简单收益率的均方根（不含脉冲窗口本身，有效值 ≥ 95%，否则缺失、不触发）；σ_ref 冻结为 Checkpoint 1 的 0.0008088465199541001（显示为 0.0008088465），即全 IS 可交易分钟 σ7d 的中位数。A5、B5 在本计划与全部报告中标注为“全 IS 波动标定的稳健性版本”：σ_ref 用了全 IS 的波动率中位数，不得宣称 A5、B5 在 IS 内完全无前视；如将来用于 IS 之外，必须原样沿用这一常数。Checkpoint 1 表 10 的数字只是固定持仓日程下的估算计数，不是 A5、B5 的实际成交笔数。百分比口径与 Z 口径版本之间的任何比较只使用触发时刻 ≥ 2020-01-07 15:51（σ7d 首次有效）的交易；主窗口自动满足这一条件。

### 2.3 方向不明分钟

同一分钟在版本自身阈值口径下同时满足向上与向下条件时：双向版本（B3、B5）跳过、不入场；单方向版本只检查自身方向（A1、A2、A3、A5、B1、B2、B4 在向上条件成立时做多，不论向下条件是否同时成立；A4 在向下条件成立时做多，不论向上条件）。主窗口内这样的分钟在百分比口径下有 604 个，在 Z 口径下有 267 个。

### 2.4 入场资格

触发分钟 t 成为版本 V 的入场信号，当且仅当同时满足：T 在主窗口内；V 自身方向的触发条件成立（双向版本恰有一个方向成立）；没有维护污染；决策时 ATR_15m 已完成初始化；入场 K 线 t+1 不是 `bad` 分钟（否则信号作废，不顺延）；基准成交量有定义；A 组还要求 S6 箱体条件成立（第 3 节）；冻结的止损价有限且位于亏损一侧，即 s·(E_ref − SL) > 0（否则剔除并计为 `invalid_stop`）。持仓期间与冷却期内出现的信号直接忽略，不排队、不顺延。

排除计数有两种，都写入 `cp2_feature_checks.json` 并在第 3 阶段的对账中报告。逐项计数 `skipped` 对窗口内自身方向的触发分钟分别统计每一项条件不满足的分钟数，可以重叠（同一分钟可同时计入“方向不明”与“维护污染”），其中 `invalid_stop` 只在其余条件都满足的分钟上定义。互斥计数 `skipped_exclusive` 按上一段的顺序（方向不明 → 维护污染 → ATR 未就绪 → 入场 K 线为 `bad` → 基准成交量无定义 → S6 箱体 → 止损无效）为每个被排除的分钟只记第一个不满足的条件，满足恒等式“窗口内自身方向触发分钟数 = 入场信号数 + 各项互斥排除之和”（代码在每次构造版本输入时核对）。在附录 A 的触发前统计中，维护污染、ATR_15m 未就绪、入场 K 线为 `bad`、基准成交量无定义与 `invalid_stop` 五项在主窗口内的排除数都是 0（主窗口之前已有约 60 天数据，基准成交量恒有定义）；S6 箱体条件的排除数见附录 A“箱体排除”列，双向版本的方向不明跳过数见“方向不明跳过”列。

## 3. A 组日线箱体（S6 主口径）

UTC 日线由 1m 按 UTC 00:00 边界聚合，`available_time = open_time + 24h`。决策分钟 T 只使用 `available_time ≤ T` 的日线，即 `as_of(T) = floor_day(T)`；这一时点规则沿用 Checkpoint 1，不改为 ATR_15m 的读取规则。成交量分布用 [as_of − 60d, as_of − 1d] 的 60 根已收盘日线对应的全部永续 1m K 线：每根 1m 的成交量在其 [low, high] 内均匀分配到 50 个等宽价格桶（桶边界为窗口最低价到最高价的等分），POC 为最大桶的中心，70% 价值区按 `ppvp_engine._value_area` 扩展，得到 VAL_1D、POC_1D、VAH_1D。ATR_1D(14) 为日线 Wilder ATR（首值为前 14 个 TR 的均值），as_of 日使用 as_of − 1d 收盘时的值，价格预热拼接 2019-09 起的现货日线。成交量分布不跨市场拼接，第一个完整 60 日窗口的 as_of 为 2020-03-01。

主口径为 Checkpoint 1 已实现的 S6（`daily.box_state(..., exit_above_poc=True)` 与 `daily.minute_box_ok`；口径名冻结为 `versions.BOX_STATE_VARIANT = 'S6_reentry_above_poc'`，真实数据上的逐分钟 `box_ok` 只能经由 `features.s6_box_ok` 构造）：在过去 30 根已收盘日线 [as_of − 30d, as_of − 1d] 中存在 j1 < j2，使日线 j1 与 [VAL_1D − 0.5·ATR_1D, VAL_1D + 0.5·ATR_1D] 相交（low ≤ 上沿且 high ≥ 下沿），日线 j2 满足 High[j2] ≥ VAL_1D + 1.3·ATR_1D（即支撑带上沿 + 0.8·ATR_1D）且 High[j2] > POC_1D；并且当前信号分钟的收盘价 C_T 位于 [VAL_1D − 0.5·ATR_1D, POC_1D]。VAL、POC、ATR 均取 as_of 时的值。不附加“仅首次回入可交易”或“每个支撑只消费一次”之类的状态限制：只要条件成立，同一箱体内可以多次入场（仍受单仓互斥与冷却约束）。主窗口内 1,401 个 as_of 日中 818 个满足二段条件，箱体内分钟占 18.4%。

以下口径只在第 4 阶段作为敏感性运行（A1–A4 的成交笔数与逐笔统计），不参与任何门禁或胜出判定，实现与 Checkpoint 1 完全相同（`daily.build_box_states` 与 `tools/run_impulse_cp1.py` 的 `box_mask`）：Checkpoint 1 原状态主口径（不要求越过 POC）；S7（原状态，且 C_T 低于反弹线 VAL + 1.3·ATR）；S1a（分布改用 1H K 线）；S1b（分布改用 60 根日线）；S2（允许 j1 = j2）；S3（参考价改为脉冲起点收盘价：该方向指标 ② 成立用 C_{T−15}，否则用 C_{T−5}）；S4（用 2019-11/12 现货 1m 成交量拼接预热）；S5（触及与反弹按触及当日的支撑带判定）；S8（反弹按日线收盘价判定）；S9（分布用 60 根日线并以 2019-09 起的现货日线价格与成交量预热）。为了可比，这些敏感性一律使用第 1.3 节的主窗口。

## 4. 三种“15 分钟”

代码中三者严格隔离，互不复用。

### 4.1 脉冲收益 r15

滚动 15 分钟收益 C_T / C_{T−15} − 1（第 2.1 节，`signals.py`）。

### 4.2 ATR_15m(14)

按 UTC 自然整刻 00 / 15 / 30 / 45 分划分 15m 桶（origin = epoch，label = left，closed = left），每桶只聚合其中有效（`~bad`）的 1m：有效分钟数 n_valid ∈ 0..15，开盘价为第一根有效 1m 的开盘价，最高 / 最低为有效分钟的极值，收盘价为最后一根有效 1m 的收盘价。1 ≤ n_valid ≤ 15 的桶正常计算 TR = max(H − L, |H − prev_valid_close|, |L − prev_valid_close|)（历史上第一根有效桶取 H − L），随后 prev_valid_close 更新为该桶收盘价。n_valid = 0 的桶没有有效价格：不计 TR，ATR 不衰减（沿用上一有效值），prev_valid_close 保持停机前最后一根 n_valid ≥ 1 的桶的收盘价，停机恢复后的第一根有效桶用它计算 TR。前 14 个有效 TR 的算术均值为首个 ATR，其后 ATR_k = (13·ATR_{k−1} + TR_k) / 14；初始化之前 ATR 为 NaN，一律不得交易。读取时点：触发 K 线 T 在 T + 1min 决策时，只读取收盘时间 ≤ T + 1min 的最近一根已收盘桶（桶序号 floor((T + 1min) / 15min) − 1），绝不读取未闭合的桶。实现为 `features.atr15_natural`。IS 共 140,256 个桶，其中 n_valid = 0 的 6 个、部分有效的 7 个；主窗口内每个分钟都有已初始化的 ATR，ATR_15m / C 的中位数为 40.4bp。

### 4.3 持有期合成 15m 棒与量能延续判别

信号 K 线 t 收盘触发、t+1 开盘入场后，以入场时刻为锚点每 15 根 1m 构成一根合成持仓棒：第 1 根 = 1m 棒 t+1 … t+15，即 [T + 1min, T + 16min)；第 2 根 = t+16 … t+30，即 [T + 16min, T + 31min)。合成棒绝不按 UTC 自然整刻对齐（自然对齐只作第 4 阶段敏感性，第 11 节）。

第 1 根满时（t+15 收盘）计算放量比 v1 = Σ_{j=t+1..t+15} V_j / B_t 与顺向收盘强弱 k1 = s·(2C − H − L) / (H − L)，其中 H、L 为第 1 根合成棒的最高、最低价，C = C_{t+15}，s 为方向符号。基准 B_t 为入场前紧邻的 20 个不重叠 15 分钟窗口 [T − 299min, T + 1min) 各自成交量之和的中位数（第 k 个窗口为 [T + 1min − 15(k+1) min, T + 1min − 15k min)，k = 0..19，含触发 K 线本身；`bad` 分钟成交量记 0；20 个数的中位数取第 10、11 个顺序统计量的平均）。v1 ≥ 1.3 且 k1 ≥ 0.10 时继续持有第 2 根，否则在 t+15 收盘离场；B_t ≤ 0 或第 1 根合成棒 H = L 时按不满足处理。第 2 根满时（t+30 收盘）无条件离场。B4 在第 1 根满时一律离场（仍计算并记录 v1、k1 供诊断）。实现为 `features.baseline_median` 与 `engine._trade_path`。

## 5. 撮合与记账（`impulse_study/engine.py`）

s = +1 表示多头、−1 表示空头；fee 为单边 taker 费率，slip_entry、slip_exit 为入场、离场的不利滑点率；所有成交都是 taker 市价成交，数量连续（不做最小下单量或价格最小变动单位的取整）。

### 5.1 入场与数量

订单在信号 K 线 t 收盘时提交。下单参考价 E_ref = C_t；当时净值 Equity_t 等于现金（单仓制下此时必然空仓）；风险预算 R_t = 0.005·Equity_t；预计往返摩擦率 c_rt = 2·fee + slip_entry + slip_exit（主成本下 0.0017）。以损定仓（主口径）q_t = min(R_t / (max(|E_ref − SL|, 0.0015·E_ref) + c_rt·E_ref), 2.0·Equity_t / E_ref)；等名义对照 q_t = 1.0·Equity_t / E_ref。2.0x 与 1.0x 都是按 E_ref 计的名义上限；分母中的 0.0015·E_ref 下限只限制数量，绝不移动实际止损价。数量在 t 收盘冻结，不随下一根开盘价回改。实际成交价 Entry_fill = O_{t+1}·(1 + s·slip_entry)，只用于成交与记账，入场手续费 = fee·q·Entry_fill。

### 5.2 止损定位（t 收盘时完全确定并冻结）

回溯窗口 W 只看本版本自身阈值口径、本笔信号所依据的脉冲方向的指标（使用 SL_B / SL_C 的版本中这一方向都等于入场方向）：该方向指标 ② 成立（含 ① + ② 同时成立）取 W = 15，仅指标 ① 成立取 W = 5；不得用反方向的指标或另一种阈值口径决定 W。脉冲起点极值：多头 L_origin = min(C_{t−W}, min_{j ∈ [t−W+1, t]} L_j)，空头 H_origin = max(C_{t−W}, max_{j ∈ [t−W+1, t]} H_j)。三种止损价：SL_A = E_ref − s·2.5·ATR_15m（不需要 W）；SL_B 多头 L_origin − 0.1·ATR_15m、空头 H_origin + 0.1·ATR_15m；SL_C 多头 C_t − 0.5·(C_t − L_origin)、空头 C_t + 0.5·(H_origin − C_t)。ATR_15m 为第 4.2 节在 t 决策时可读的值。止损价在持仓期间不移动（无追踪、无保本），也不按 O_{t+1} 重算。实现为 `features.origin_extremes` 与 `features.build_version_inputs`。

### 5.3 止损成交与同分钟优先级

持仓的每一分钟 m（从 t+1 到离场分钟）先检查止损，再检查时间离场。入场分钟 t+1 的开盘若已越过止损（多头 O_{t+1} ≤ SL，空头 O_{t+1} ≥ SL），保留开仓成交，随即按 O_{t+1}·(1 − s·slip_exit) 平仓，开平两边分别计 taker 费，离场原因 `stop_gap_at_entry_open`；不抹除这笔交易，也不按更有利的 SL 价离场。此后任一持仓分钟 m 开盘跳空越过 SL，按 O_m·(1 − s·slip_exit) 离场（`stop_gap_open`）。开盘未越过、但盘中触及（多头 L_m ≤ SL，空头 H_m ≥ SL）时按 SL·(1 − s·slip_exit) 离场（`stop_intrabar`）。在第 1 根合成棒末分钟（t+15）与第 2 根末分钟（t+30），若该分钟盘中触及止损，一律按止损成交，不按收盘时间离场或量能离场结算（保守最坏路径）。分钟内的先后只用到“开盘是该分钟第一笔价格”这一事实，不做其他分钟内路径假设。

### 5.4 时间离场

第 1 根满时不满足延续条件（或 B4）按 C_{t+15}·(1 − s·slip_exit) 离场（`time_bar1`）；第 2 根满时按 C_{t+30}·(1 − s·slip_exit) 离场（`time_bar2`）；均计 taker 费，离场手续费 = fee·q·Exit_fill（Exit_fill 为含滑点的离场成交价，所有离场类型相同）。无停机时最长持仓 30 分钟；持仓中遇到维护停机时按第 5.5 节在停机后第一根有效 1m 开盘离场，可晚于 t+30。

### 5.5 维护停机

持仓期间遇到 `bad` 分钟时，停机期间不做任何止损或时间判断，在停机结束后第一根有效（`~bad`）1m 的开盘按 O·(1 − s·slip_exit) 强制离场并计 taker 费（`halt_forced_exit`），随后按该开盘时刻正常进入 15 分钟冷却。这一规则优先于第 5.3 节与第 5.4 节：恢复开盘即使已越过 SL，离场原因也记为 `halt_forced_exit`（价格与离场时刻与跳空止损相同，只是标签）；停机覆盖 t+15 或 t+30 时不做延续判别，持仓可超过 30 分钟。入场 K 线必须有效、且停机后 15 分钟内的触发都属维护污染，因此停机只可能打断一笔停机前已开的仓位。停机若延续到数据末端，计划没有定义离场，引擎直接报错而不是编造一个离场价；IS 内不会发生（最后一次停机在 2023-09-12，最后触发之后恰有 30 分钟数据）。

### 5.6 资金费

结算时点 τ 的费率 r_τ 只在入场时刻 < τ ≤ 离场时刻时收付，金额 = −s·q·P_τ·r_τ（正费率多头付、空头收，负费率相反），一笔交易内的结算次数不设上限。P_τ 取恰在 τ 开盘的那根 1m 的开盘价；时间离场恰在 τ 收盘时取该分钟收盘价；结束于 τ 的那一分钟内的盘中止损发生在 τ 之前，不收付 τ；在 τ 开盘跳空止损时 τ 时仍持仓，按 O_τ 收付；停机期间与恢复开盘时刻的结算照收付，停机期间的价格取占位分钟的开盘价（等于停机前最后收盘价），恢复开盘时刻取该分钟的开盘价。恰在 IS_END 的结算不读取、不收付（只影响恰在 2024-01-01 00:00 收盘离场的交易）。交易所实际按标记价格结算，本研究用 1m 成交价近似。零成本毛收益情景不计资金费；台账的结算次数 `n_funding` 是资金费窗口内的结算次数，零成本情景下照常计数、但金额为 0。

### 5.7 单仓互斥与冷却

同一时刻最多一笔仓位。离场时刻的定义：开盘类离场（入场跳空、跳空止损、停机强制离场）为该分钟开盘时刻；盘中止损与时间离场为该分钟收盘时刻。下一次入场时刻 ≥ 离场时刻 + 15min，即下一个可接受的触发 K 线索引 ≥ 离场时刻所在分钟索引 + 14。由此，持满 2 根后下一触发须 ≥ T + 45min，第 1 根后离场须 ≥ T + 30min，入场分钟内盘中止损须 ≥ T + 16min，入场开盘跳空离场须 ≥ T + 15min。

### 5.8 净值、盯市与台账

现金记账：入场时扣入场费；持仓分钟 m 的净值 = 现金 + s·q·(C_m − Entry_fill)，其中现金已计入 τ ≤ 分钟 m 开盘时刻的资金费（结算记入以 τ 为开盘的那一分钟的净值）；离场分钟的净值为平仓后现金，含恰在时间离场收盘时刻 τ 的结算；空仓分钟为现金；2020-03-01 之前无定义。由此，持仓跨越 UTC 0 点时 0 点的结算计入次日第一分钟，而恰在 23:59 收盘离场的交易其 0 点结算计入当日最后一分钟；两者只影响相邻两日之间约 q·P·r（约为净值的 10⁻⁵ 至 10⁻⁴）的归属。日净值取每个 UTC 日最后一分钟的值（2020-03-01 至 2023-12-31 共 1,401 天），日收益 r_d = E_d / E_{d−1} − 1，E_0 = 100,000（`engine.run_portfolio` 返回的日净值不含 E_0，统计时在首日之前补上）。

台账每笔记录：触发 / 入场 / 离场时间与索引、方向、离场原因、SL、E_ref、q、入场开盘价与成交价、离场参考价与成交价、两边手续费、资金费与结算次数、参考价毛盈亏、净盈亏、v1、k1、延续检验结果 `cont`、MAE / MFE、信号时净值、触发类别、W、ATR_15m、`cap_bound` 与 `floor_bound`（以损定仓时 2.0x 上限、0.15% 下限是否决定了数量；等名义口径下恒为假）。`cont` 是第 1 根合成棒满时延续检验的结果：1 满足、0 不满足（含 B_t ≤ 0 或 H = L）、−1 未检验（在 t+15 收盘之前已离场，包括在 t+15 分钟内止损）；B4 照常检验、只作诊断，因此 B4 的 `cont = 1` 不表示实际延续。v1、k1 各自在可计算时记录（B_t > 0、H > L），未检验的交易两者都缺失。MAE / MFE 为持仓期间最不利 / 最有利价格相对入场开盘价的偏离 s·(P − O_{t+1})（MAE ≤ 0 ≤ MFE），持仓各有效分钟取其最高、最低价（`bad` 占位分钟不是成交价，不计入）；盘中止损所在分钟只计该分钟开盘价与止损价（分钟内止损之后的价格不计），跳空离场与停机强制离场只计离场开盘价，入场开盘跳空离场记 0。派生量：gross_bps = s·(离场参考价 − O_{t+1}) / E_ref × 10⁴（不含任何成本）；net_bps = 净盈亏 / (q·E_ref) × 10⁴；net_R = 净盈亏 / (q·|E_ref − SL|)；风险金额 q·|E_ref − SL|；按 E_ref 计的名义杠杆；`bars_held`（t+1 至离场分钟、含两端的 1m 根数，与 `has_archive_gap` 的覆盖范围相同，入场开盘跳空离场为 1）；`minutes_held`（持仓时长 = 离场时刻 − 入场时刻，以分钟计，入场开盘跳空离场为 0）；`has_archive_gap`（持仓分钟 t+1 至离场分钟覆盖 Checkpoint 1 表 5b 的漏记分钟）；`signal_lookback_has_archive_gap`（触发回看 [t−15, t] 覆盖漏记分钟）；`halt_in_holding`。没有成交的版本也返回列与类型完整的空台账。离场只取决于价格路径与冻结的止损价，因此同一版本在 4 种成本与 2 种仓位下的成交清单逐笔相同，逐笔 bp 与 R 与仓位口径无关（有测试核对）。

引擎对输入做合法性检查，不合法即报错而不是静默处理：窗口内的信号方向只能是 ±1，入场 K 线 t+1 必须在网格内且有效，E_ref 与 SL 有限且 SL 位于亏损一侧，基准成交量有定义；`simulate_events` 另要求事件在上下文的交易窗口内、没有维护污染、其后至少还有 30 分钟数据。

### 5.9 不建模的事项

不建模强平（名义杠杆 ≤ 2.0x、持仓一般 ≤ 30 分钟，需要约 50% 的不利波动才会触及）、滑点假设之外的市场冲击与容量、maker 挂单与返佣、下单延迟（一律按下一根开盘成交）、部分成交，以及标记价格与成交价的差异。

## 8. 统计方法

### 8.1 指标

逐笔主指标为主成本下的 net_bps（以 q·E_ref 为分母，与仓位口径无关）；同时报告 gross_bps、net_R、胜率与离场原因构成。组合层面用第 5.8 节的 1,401 个日收益计算年化夏普，并描述性地报告总收益、最大回撤、持仓时间占比（Σ `minutes_held` / 主窗口分钟数）、资金费合计与 2.0x 上限的生效笔数（按台账 `cap_bound` 计数，不用浮点的杠杆值判断）。全部统计只覆盖主窗口内的交易（按入场时刻归属）。进入第 8、9 节的任何统计之前先核对：台账的触发时刻落在 [2020-03-01 00:00, 2023-12-31 23:29]，入场时刻 ≤ 2023-12-31 23:30，离场时刻 ≤ 2024-01-01 00:00，日收益索引落在 [2020-03-01, 2023-12-31]，越界即抛出 `impulse_study.scope.ScopeError`。旧轮的 `metrics._check_series_extent` 只拦截 2025-07-01 之后的数据，不能作为本研究的越界保护。

### 8.2 按月聚类（主口径）与按日聚类（辅助）

聚类为入场时刻所在的 UTC 自然月，月份按时间升序编号。记 N 为交易笔数，G 为含有交易的月份数，K_g、S_g 为第 g 个月的笔数与统计量之和，x̄ = Σ_g S_g / N。

单个版本的 95% 区间（报告用）：在 G 个月份中有放回地抽取 G 个月（下标 `rng.integers(0, G, size=(10000, G))`），统计量为抽中各月 S_g 之和除以抽中各月 K_g 之和（逐笔等权的均值），取 2.5% 与 97.5% 分位数（`numpy.percentile`，线性插值）为百分位 95% 区间。这与 `ppvp_audit.nulls.cluster_bootstrap_mean(x, 月份, 10000, seed)` 完全相同，种子按第 8.6 节显式传入；它同时返回的百分位 p 值 `p_le_0` 只作报告，不用于任何门禁。

单个版本“均值 > 0”的单侧 p 值（门禁用）：按月聚类的受约束野自助 t 检验（wild cluster restricted bootstrap-t，Webb 六点权重）。t = x̄ / se，se² = G/(G−1)·Σ_g (S_g − x̄·K_g)² / N²。在原假设均值为 0 下，B = 9,999 次重抽样中每次为每个月独立抽取一个权重 w_g（`rng.choice(np.array([-np.sqrt(1.5), -1.0, -np.sqrt(0.5), np.sqrt(0.5), 1.0, np.sqrt(1.5)]), size=(9999, G))`，行为重抽样、列为按时间升序的月份），令 S*_g = w_g·S_g、x̄* = Σ_g S*_g / N、se*² = G/(G−1)·Σ_g (S*_g − x̄*·K_g)² / N²、t* = x̄* / se*；p = #{t* ≥ t} / 9999。se* = 0 的重抽样记 t* = 0。

两个版本的差值 D = x̄_A − x̄_B（第 9.2 节的箱体配对等）：月份全集取两者任一有交易的 G 个月份（升序编号），某版本在某月没有交易时其 S_g = K_g = 0。区间：同一组下标 `rng.integers(0, G, size=(10000, G))` 同时用于两个版本，D* 为两者重抽样均值之差；任一版本在某次重抽样中笔数为 0 时舍弃该次（不补抽）并记数，分位数在保留的重抽样上计算。p 值：在原假设 μ_A = μ_B 下，取两版本全部交易合并后的均值 μ̃ 为受约束估计；影响量 φ_g = Σ_{i∈A,g}(x_i − x̄_A)/N_A − Σ_{i∈B,g}(x_i − x̄_B)/N_B，se_D² = G/(G−1)·Σ_g φ_g²，t = D / se_D。每次重抽样每个月抽一个 Webb 权重（与单版本相同的调用，形状 (9999, G)），同时作用于该月两个版本的全部交易：x*_i = μ̃ + w_g·(x_i − μ̃)；由 x* 按同样公式重算 D* 与 se*_D，t* = D* / se*_D。正方向 p = #{t* ≥ t} / 9999，负方向 p = #{t* ≤ t} / 9999。区间与 p 值各用第 8.6 节的一个种子、各自新建一个生成器。

门禁 G2、G3 与 F3 一律以野自助 p 值为准；百分位区间只作报告。在有效月份数约 11 的月度集中度下，百分位区间系统性偏窄（第 0 节第 6 项），两者在边界附近可能不一致，此时以 p 值为准。按日聚类的区间与 p 值用完全相同的方法、以入场 UTC 日为聚类，只作辅助报告。主检验始终是按月聚类的结果，不因任何结果切换。

### 8.3 匹配随机入场对照

对版本 V（序号 v，第 8.6 节）在主配置下的全部实际交易，按触发分钟索引升序逐笔处理。交易 i 的分层键为（触发分钟所在 UTC 自然月，触发分钟开盘时刻的 UTC 小时，ATR 档）。分层用触发分钟，第 8.2 节的聚类用入场时刻，两者只在月末最后一分钟触发时归属不同的月。ATR 档按决策值 a = ATR_15m / C_T 划分：q1、q2 = `numpy.quantile(a_all, [1/3, 2/3])`（默认线性插值），a_all 为主窗口内全部非 `bad` 且 ATR 已就绪分钟的 a，对所有版本相同；a ≤ q1 为第 1 档，q1 < a ≤ q2 为第 2 档，a > q2 为第 3 档。

候选池为主窗口内满足版本 V 除触发条件以外全部入场资格的分钟：无维护污染、ATR_15m 已就绪且 > 0、入场 K 线 t+1 有效、基准成交量有定义；A 组版本还要求 S6 箱体条件成立；Z 口径版本还要求 σ7d 有效。候选池排除 V 自身阈值口径下任一方向触发条件成立的分钟。层内不同候选分钟少于 20 个时，依次放宽为（自然月，6 小时时段 [00, 06) / [06, 12) / [12, 18) / [18, 24)，ATR 档）、（自然月，ATR 档）、（自然月）。放宽到（自然月）仍少于 20 个时不再放宽，使用该月全部候选；该月没有候选时，该笔交易的 x_i 记为缺失、不进入 G3，并单列计数。报告各级放宽的次数与缺失笔数。

抽样：rng = `numpy.random.default_rng(SEED_BASE + 100 + v)`。对每笔交易，把其最终层的候选分钟索引升序排列为数组 pool，取 `pool[rng.integers(0, len(pool), size=100)]`（K = 100，有放回）；x_i 缺失的交易不调用 rng。同一组抽取用于 4 种成本情景。

每个随机入场与原交易同方向，E_ref 取候选分钟收盘价，止损价 = E_ref − s·d_i·ATR_cand，其中 d_i = |E_ref,i − SL_i| / ATR_i 是原交易以 ATR_15m 计的止损距离（因此 SL_A 版本的随机入场恰为 2.5·ATR）。持有规则（量能延续或 B4 的固定 1 根）、成本情景与资金费与原版本相同，用 `engine.simulate_events` 逐个独立模拟（单位数量，不经过单仓互斥与冷却），得到净 bp。交易 i 的超额 x_i = net_bps_i − 其 100 个随机入场净 bp 的算术平均。x_i 的两边扣同一成本情景，摩擦在差值中抵消：G3 回答“扣除同样成本后是否优于同层随机入场”，是否覆盖 17bp 摩擦由 G2 回答，所以第 9.3 节要求两者同时成立。门禁 G3 的统计量为非缺失 x_i 的均值，按交易的入场月份做第 8.2 节的按月聚类检验。

辅助的随机化零分布：rng = `numpy.random.default_rng(SEED_BASE + 900 + v)`，J = `rng.integers(0, 100, size=(5000, N))`（N 为 x_i 非缺失的交易数，列按触发分钟升序）。第 b 次的零均值为各交易第 J[b, i] 个随机入场（取自已模拟的 100 个，不重新抽候选）主成本净 bp 的平均；p 值为零均值 ≥ 这 N 笔交易 net_bps 均值的比例。另报告平衡诊断：实际交易与其随机入场在 a、UTC 小时与止损距离（bp）上的分布对照。第 3 阶段的候选池必须按本节构造，不得沿用耗时基准脚本中的简化候选条件。

### 8.4 夏普与配对夏普差（按月块重抽样为主口径）

日收益序列为 2020-03-01 至 2023-12-31 的 1,401 个 r_d，索引为 UTC 日期（第 5.8 节，首日之前补 E_0 = 100,000）。年化夏普 = mean(r_d) / sd(r_d) × √365（ddof = 1）。区间按月聚类：主窗口的 46 个 UTC 自然月（2020-03 至 2023-12）按时间升序编号，每次有放回地抽取 46 个月（下标 `rng.integers(0, 46, size=(5000, 46))`），按抽中的顺序把各月的全部日收益拼接后计算年化夏普，重复 5,000 次，取百分位 95% 区间；标准差为 0 或结果非有限的重抽样舍弃并记数，分位数与比例在其余重抽样上计算。两个版本的夏普差对两条序列使用同一组月份下标。“X 优于 Y”的单侧 p 值为重抽样差值 ≤ 0 的比例；双侧 p 值为 min(1, 2·min(差值 ≤ 0 的比例, 差值 ≥ 0 的比例))，两个比例都直接由重抽样差值计算；X 为配对中先写的版本，F5 中为候选。按月块重抽样在 A 组的月度集中度下仍略偏松（合成模拟中名义单侧 2.5% 的实际水平约 3.5%–4.7%），第 4 阶段的结论须注明这一点。平稳自助法（`attribution.stationary_bootstrap_sharpe` 与 `attribution.paired_sharpe_diff`，平均块长 10 天，benchmark_factor = 1，种子与对应主检验相同并显式传入）只作辅助报告。

### 8.5 多重比较

全部用 Holm 逐步校正（`ppvp_audit.experiments.holm`），族的划分事先固定：F1 为门禁 G2 的 10 个版本；F2 为门禁 G3 的 10 个版本；F3 为箱体贡献的 2 个配对，正方向与负方向各自成族；F4 为止损比选的 4 个配对（A1–A2、A1–A3、A2–A3、B1–B2）；F5 为第 9.5 节中候选版本与 P 中其余每个版本的比较（|P| − 1 个检验）。F1、F2、F3 的单侧检验水平为 0.025（与 95% 双侧区间对应），F4 的双侧检验水平为 0.05，F5 的双侧检验水平为 0.025（第 9.5 节）。显著性一律按“校正后 p ≤ 水平”判定。

## 9. 判定规则（第 4 阶段终审）

### 9.1 门禁

版本 V 在主配置下逐项检查：

1. G1 样本量：主窗口内成交 ≥ 200 笔。
2. G2 覆盖 17bp 摩擦的净期望：net_bps 均值的按月聚类野自助单侧 p 值（第 8.2 节），在 F1 内经 Holm 校正后 ≤ 0.025。
3. G3 超越匹配随机：第 8.3 节超额 x_i 均值的按月聚类野自助单侧 p 值，在 F2 内经 Holm 校正后 ≤ 0.025。
4. G4 组合层面：年化日夏普的按月块重抽样 95% 区间（第 8.4 节）下限 > 0。
5. G5 时间稳定：两个半段 [2020-03-01, 2022-01-01) 与 [2022-01-01, 2024-01-01) 的 net_bps 均值（点估计）都 > 0。
6. G6 成本压力：harsh_34bp 下 net_bps 均值（点估计）> 0。这一项相当于要求逐笔毛收益约超过 34bp 加资金费，是有意从严的。
7. G7 非集中：去掉 net_bps 合计最大的 3 个入场自然月的全部交易后，其余交易的 net_bps 均值（点估计）> 0。

A5、B5 另需 G8z：在第 11 节第 5 项的因果 σ_ref 敏感性下（主窗口、主配置），net_bps 均值（点估计）> 0，以确认结论不依赖全 IS 标定的常数。

### 9.2 (a) 日线箱体是否有真实正贡献

对 A1 vs B1 与 A2 vs B2 两个配对，统计量 D = 均值 net_bps(A) − 均值 net_bps(B)，用第 8.2 节的配对按月聚类检验（区间为百分位区间，p 值为野自助 t 检验）。正方向与负方向的单侧 p 值各自在 F3 内做 Holm 校正，水平 0.025。结论按下列顺序取第一个成立者：

1. “两个配对方向相反，箱体效果依赖止损口径，不能认定为真实的正贡献或负贡献”：一个配对正方向显著，另一个配对负方向显著。
2. “箱体有可交易的正贡献”：至少一个配对正方向显著，该配对的 D 在两个半段的点估计都 > 0，且该配对的 A 版本通过 G2。
3. “箱体有统计上可信的相对改进，但未达到可交易正贡献的标准”：至少一个配对正方向显著，但上一条的其余条件不全满足；结论逐项写明未满足的条件（D 在哪个半段 ≤ 0；A 版本未通过 G2 时写明“箱体版本本身不能覆盖 17bp 摩擦”）。
4. “箱体有可信的负贡献”：至少一个配对负方向显著，且没有配对正方向显著。
5. “没有可信证据表明箱体有正或负贡献”：其余情形。

同时报告：以 gross_bps 与 net_R 计的 D，两个配对的日夏普差（第 8.4 节的配对按月块重抽样，说明 A 的交易频率远低于 B），按年份的 D，以及 B1、B2 实际成交中触发分钟在 S6 箱体内与箱体外两组的 net_bps 之差（按月聚类）。

### 9.3 (b) 纯时间价格脉冲是否有超越匹配随机与 17bp 摩擦的净 Alpha

当且仅当 B1–B5 中至少一个版本同时通过 G1、G2、G3 时，结论为“纯时间价格脉冲存在超越匹配随机与 17bp 摩擦的净 Alpha”，并列出这些版本及其 G4–G7 的结果。若满足条件的只有 B5，B5 还须通过 G8z 结论才成立，并须注明它是全 IS 波动标定的稳健性版本；B5 未通过 G8z 时，结论为“没有可信证据表明纯时间价格脉冲有超越匹配随机与 17bp 摩擦的净 Alpha”，并单独说明 B5 的 G1–G3 结果依赖全 IS 标定的常数。其余情形结论为“没有可信证据表明纯时间价格脉冲有超越匹配随机与 17bp 摩擦的净 Alpha”。A 组版本的 G2、G3 结果并列报告。它们只经由 F1、F2 的 Holm 校正影响这一条（族内 10 个版本共同校正，A 组的原始 p 值会改变 B 组版本的校正倍数，这一点事先接受），此外不改变这一条的结论。

### 9.4 (c) 哪种客观止损最优

在同入场族 {A1, A2, A3} 与 {B1, B2} 内，以主配置的年化日夏普为主指标，对 F4 的 4 个配对计算配对夏普差（第 8.4 节，先写的版本为 X）与双侧 p 值并做 Holm 校正（水平 0.05）。一个止损在其族内被判为最优，当且仅当它的夏普点估计最高，且它与族内每一个其他成员的配对中，差值的点估计有利于它、F4 内 Holm 校正后的双侧 p ≤ 0.05（“显著为正”即指这两条同时成立）。族内无人满足时结论为“该族内没有可区分的最优止损”。族内全部成员的夏普都 < 0 时，结论须注明“相对比较只说明亏损程度的差别”。两族的结论分别报告；只有同一种止损在两族中都被判为最优时，才表述为“该止损在两族中均最优”。逐笔 net_R、net_bps（按月聚类区间）、止损出场占比与图 2 的 MAE 证据作为辅助，不改变上述判定。

### 9.5 (d) 是否存在唯一胜出版本具备申请后续 OOS / ETH 一次性验证的资格

记 P 为通过 G1–G7（A5、B5 另加 G8z）的版本集合。P 为空时，结论为“没有版本具备申请资格”；通过 G1–G5 与 G7、只在 G6 失败的版本单独标注为“成本敏感的候选，不具备申请资格”。P 恰有一个版本时，它是唯一胜出版本。P 有多个版本时，取主配置年化日夏普点估计最高者为候选；它与 P 中其余每个版本的配对夏普差（候选为 X）的双侧 p 值在 F5 内经 Holm 校正后都 ≤ 0.025、且差值点估计都 > 0 时，它是唯一胜出版本；否则结论为“存在多个达标版本，没有唯一胜出”，并列出 P。候选是按点估计选出的，在选出的方向上做单侧 0.025 的检验相当于双侧 0.05，会使两个真实夏普相同的版本中约 5% 的情形被错判为有胜者；因此这里用双侧 0.025（|P| = 2 时等价于选出方向上的单侧 0.0125），使这一错判概率约为 2.5%。日夏普随交易频率上升，A 组与 B 组版本之间的比较须同时报告逐笔 net_bps、net_R 与成交笔数。唯一胜出只表示具备申请资格；是否进行一次性 OOS / ETH 验证由用户另行批准，本轮任何阶段都不运行 VAL、OOS 或 ETH。
