## 实现约定（不改研究定义）

1. 数据适配器只读复用已冻结的 BTC IS 时间谓词、原缓存内容哈希和分钟格子工具；以本研究自己的锁及独立不可写 Context 隔离。53 个现存源文件/metadata 按当前实际字节登记，保护旧解锁行的现有状态；不重新冻结旧资产。
2. 完整 1D 聚合在 UTC 使用等价的 `24h` Tick 拼写，避免 pandas 3 对 `1D` 与 epoch origin 的警告；完成时间与日线自然边界完全一致。
3. 已批准的 0.10 价格 floor、压力穿价 ceil 和数量格点 floor 用 canonical decimal 字符串做格点运算，不加 epsilon。价格公式保留原来的减法、乘法、除法和 floor，避免二进制误差使 99.3 误落成 99.2；连续指标和账户记账仍为 float64。
4. 市价激活分钟为 bad 时拒单并冷却4h，不能在占位价格成交。限价订单的延迟激活等待期也遵守遇 bad 即取消。维护恢复开盘若亦穿过止损，两种离场的成交价相同，账本保留维护覆盖标记及止损原因。
5. 当更深的压力穿价只能在分钟盘中确认，但该分钟开盘已低于 S，按计划保留限价成交及不利开盘参考退出；事件标记为盘中，冷却从分钟末起。该代理不被声称为真实盘口顺序。
6. `gross_bps` 为无滑点入、出参考价差 / 信号 E_ref；实际成交差另存 `execution_pnl`，与滑点成本、双边费、资金费分别对账。net_bps、net_R 完全按批准计划。限价成交价不高于 L。
7. 空交易/订单账本仍有固定列与 UTC ns 时间类型；无交易的均值/夏普标为无定义，不能伪造为零盈利。所有父信号保留在 father_signals；组合内状态跳过另记 decisions，独立事件账本不形成组合夏普。
8. 输出只从已完成的八组合及主口径事件账本生成，不因统计或作图追加策略模拟。运行错误保留 STOPPED 和已产出文件，执行器不自动重试。
